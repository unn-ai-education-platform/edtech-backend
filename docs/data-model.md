# data-model.md

## Purpose

Defines the MVP domain model and the **persistence-level invariants** currently enforced by the database schema (Flyway `V1__init.sql`).

The database is PostgreSQL, with Flyway migrations. IDs are UUIDs generated by the application.

## Entities

### Rubric (`rubrics`)

- `id: uuid` (PK)
- `name: text` (NOT NULL)
- `criteria: jsonb` (NOT NULL)
- `gradeScheme: jsonb` (NOT NULL)
- `createdBy: text` (NOT NULL)
- `createdAt: timestamptz` (NOT NULL)
- `updatedAt: timestamptz` (NOT NULL)

### Submission (`submissions`)

- `id: uuid` (PK)
- `rubricId: uuid` (FK → `rubrics.id`, NOT NULL)
- `studentId: text` (NOT NULL)
- `text: text` (NOT NULL, sensitive; do not log)
- `createdAt: timestamptz` (NOT NULL)

Indexes:
- `rubric_id`, `student_id`

### EvaluationJob (`evaluation_jobs`)

- `id: uuid` (PK)
- `submissionId: uuid` (FK → `submissions.id`, NOT NULL)
- `status: text` (NOT NULL) ∈ `{QUEUED, RUNNING, DONE, FAILED}`
- `attempts: int` (NOT NULL, ≥ 0)
- `lastErrorCode: text | null`
- `lastErrorMessage: text | null`
- `traceId: text | null`
- `createdAt: timestamptz` (NOT NULL)
- `updatedAt: timestamptz` (NOT NULL)
- `startedAt: timestamptz | null`
- `finishedAt: timestamptz | null`

**DB invariant:** max 1 active job per submission:
- UNIQUE index on `submission_id` where `status IN ('QUEUED','RUNNING')`

### AIResult (`ai_results`)

- `id: uuid` (PK)
- `submissionId: uuid` (FK → `submissions.id`, NOT NULL)
- `jobId: uuid` (FK → `evaluation_jobs.id`, NOT NULL)
- `criteriaResults: jsonb` (NOT NULL)
- `totalScoreNormalized: numeric(5,2)` (NOT NULL, 0..100)
- `model: text | null`
- `promptVersion: text | null`
- `traceId: text | null`
- `createdAt: timestamptz` (NOT NULL)

**DB invariant (MVP):** at most one AI result per submission:
- UNIQUE (`submission_id`)

Visibility rule:
- `AIResult` is internal; it must never be returned to students.

### TeacherDecision (`teacher_decisions`)

- `id: uuid` (PK)
- `submissionId: uuid` (FK → `submissions.id`, NOT NULL)
- `aiResultId: uuid | null` (FK → `ai_results.id`)
- `mode: text` (NOT NULL) ∈ `{ACCEPT_AI, OVERRIDE}`
- `criteriaResults: jsonb` (NOT NULL)
- `comment: text | null`
- `totalScoreNormalized: numeric(5,2)` (NOT NULL, 0..100)
- `finalGrade: jsonb` (NOT NULL)
- `decidedBy: text` (NOT NULL)
- `decidedAt: timestamptz` (NOT NULL)

**DB invariant (MVP):** at most one decision per submission:
- UNIQUE (`submission_id`)

**DB invariant:** `ACCEPT_AI` requires an AI result reference:
- CHECK (`mode <> 'ACCEPT_AI' OR ai_result_id IS NOT NULL`)

MVP publication model:
- There is no separate `publishedAt`.
- Creating `TeacherDecision` finalizes and makes it visible to the student immediately.
- `decidedAt` is the approval/publication timestamp in MVP.

## Relationship summary

- `Rubric 1 — N Submission`
- `Submission 1 — N EvaluationJob` (over time; only one active at once)
- `Submission 1 — 0..1 AIResult` (MVP constraint)
- `Submission 1 — 0..1 TeacherDecision` (MVP constraint)
- `TeacherDecision 0..1 — 1 AIResult` (optional reference)

## Sensitive data

- `Submission.text` is sensitive:
  - do not log it
  - do not include it in error payloads
